## Descrição do Projeto
Aplicação desenvolvida em Jupyter Notebook (`.ipynb`) para exploração e análise estatística de um dataset real de transporte de frota. O projeto implementa um núcleo estatístico próprio "na unha", cobrindo medidas descritivas, gráficos interativos, simulações de Monte Carlo, Teorema Central do Limite e Regressão Linear por Mínimos Quadrados.

## Estrutura do Repositório
* `Laboratorio_Estatistico_Frota.ipynb`: Código-fonte completo com os módulos da atividade.
* `uso_da_frota_2025.csv`: Dataset original utilizado na análise.
* `RELATORIO.md`: Relatório detalhado com fórmulas, decisões metodológicas e as 3 descobertas.

## Instruções de Execução
1. Baixe o arquivo `Laboratorio_Estatistico_Frota.ipynb` e o dataset `uso_da_frota_2025.csv` mantendo-os na mesma pasta.
2. Abra o [Google Colab](https://colab.research.google.com/).
3. Vá em Arquivo > Abrir notebook > aba **Upload** e selecione o arquivo do notebook.
4. Execute as células sequencialmente.
